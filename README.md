# 刷题记录本

一个轻量的本地刷题记录工具，支持：

- 记录题目、平台、难度、状态、标签
- 卡壳点与解决办法
- 更优解 / 其他解法
- 代码与代码文件路径
- 洛谷题号自动获取题目信息
- 搜索（题名 / 题号 / 日期 / 标签 / 代码全文）与筛选
- 点击顶部统计卡片快速筛选（再点一次取消），支持排序（最近更新 / 刷题日期 / 平台 / 题号）
- 详情弹窗内可直接进入编辑

## 本地启动

双击 **启动刷题记录本.bat**，浏览器会自动打开。

## 两种保存方式

- **本机模式**：用 `启动刷题记录本.bat` 打开时，数据存进程序文件夹的 `data.json`。
- **网页模式**：把 `web/` 部署到 Vercel 等静态平台时，数据保存在浏览器本地（localStorage），
  刷新、关掉重开都不会丢；页面顶部可导出 / 导入 JSON 备份，换个设备打开时用备份搬数据。

两种模式顶部都有「导出备份 / 导入备份」：本机模式导出 `data.json` 内容，导入为**追加**新记录（不覆盖）；
网页模式导入为**覆盖**当前记录。保存失败时记录会暂存在浏览器里，顶部出现橙色提示条可一键重试。

模式自动判断：本机、局域网地址走本机模式，其它域名走网页模式；
也可以在地址后加 `?storage=browser` 或 `?storage=server` 手动指定。
