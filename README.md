# 刷题记录本

一个轻量的本地刷题记录工具，支持：

- 记录题目、平台、难度、状态、标签
- 卡壳点与解决办法
- 更优解 / 其他解法
- 代码与代码文件路径
- 洛谷题号自动获取题目信息
- 搜索与筛选

## 本地启动

双击 **启动刷题记录本.bat**，浏览器会自动打开。

## 两种保存方式

- **本机模式**：用 `启动刷题记录本.bat` 打开时，数据存进程序文件夹的 `data.json`。
- **网页模式**：把 `web/` 部署到 Vercel 等静态平台时，数据保存在浏览器本地（localStorage），
  刷新、关掉重开都不会丢；页面顶部可导出 / 导入 JSON 备份，换个设备打开时用备份搬数据。

模式自动判断：本机、局域网地址走本机模式，其它域名走网页模式；
也可以在地址后加 `?storage=browser` 或 `?storage=server` 手动指定。
